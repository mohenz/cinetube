## 1. 작업 개요
대상 사이트(`manga18.me`)는 Cloudflare DDoS 방어망 및 만화 이미지의 지연 로딩(Lazy Loading) 기법이 적용되어 있어, 단순 HTTP 웹 크롤러나 스크래퍼로는 이미지 다운로드 및 웹페이지 복제가 차단됩니다. 
이를 해결하기 위해 **가상 브라우저 자동화 도구(Puppeteer)**를 활용하여, 실제 브라우저 세션의 보안 상태를 상속받은 방식으로 모든 이미지를 성공적으로 다운로드하고 오프라인 소장용 리더를 빌드하였습니다.

## 2. 세부 구현 기술 및 우회 전략

### A. Cloudflare 및 CORS 우회 (In-Page Context Fetch)
일반적인 Node.js 환경에서 외부 이미지 서버(CDN)로 직접 다운로드 요청을 보낼 경우 Cloudflare 보안 차단 및 CORS(교차 출처 리소스 공유) 차단에 직면하게 됩니다.
- **해결책**: Puppeteer로 대상 페이지를 완벽하게 로드한 뒤, **브라우저의 컨텍스트 내부(`page.evaluate`)에서 `fetch` API를 실행**하여 이미지를 `Blob` 형식으로 내려받고 이를 `Base64 DataURL`로 변환하여 Node.js 환경으로 전달받았습니다.
- 이 방식은 브라우저가 보유한 Cloudflare 세션 쿠키, User-Agent 및 헤더 정보를 100% 상속받아 통과하므로 차단 가능성을 원천 차단합니다.
- 브라우저 실행 인자에 `--disable-web-security` 플래그를 추가하여 타 도메인 간의 CORS 제한도 해결하였습니다.

### B. 이미지 지연 로딩(Lazy Loading) 극복
대부분의 웹툰/만화 사이트는 화면 영역에 보이지 않는 이미지를 로드하지 않습니다.
- **해결책**: 가상 크롬 브라우저 상에서 페이지 하단까지 **800px 단위로 자동 스크롤(`autoScroll`)을 반복 수행**하여 전체 만화 컷이 완전하게 DOM에 로딩 및 렌더링되도록 트리거한 후, 최종 리소스를 수집하였습니다.

### C. 노이즈 이미지 필터링 알고리즘
전체 페이지에서 추출된 34개의 이미지 요소 중 광고, 아바타, 로고, 타 만화 썸네일 등을 걸러내야 했습니다.
- **해결책**: 가로/세로 해상도가 150px 미만이거나, URL 경로 내에 `logo`, `avatar`, `banner`, `loading` 등의 키워드가 포함된 이미지를 자동 제외 처리하여 **실제 만화 본문 이미지 30장**만을 정확하게 선별하였습니다.

  - 웹툰 감상에 최적화된 연속형 종스크롤 레이아웃 적용.
