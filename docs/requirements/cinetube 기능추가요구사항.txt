기능추가 요구사항

1. 찜하기같은 관심작품 기능 넣기
일자 : 2026.06.06 
유형 : 신규
현황 : 완료
내용
- 선택한 영역의 오른쪽에 "♥관심작품" 버튼을 추가
- 관심작품으로 선택한 작품은 왼쪽 메뉴 '관심작품' 메뉴를 추가해서 
- 관심작품을 볼 수 있는 작품으로 이동하는 화면을 제공
- 관심작품은 선택과 해제를 통해서 관심작품에 넣고 뺄 수 있는 기능 제공

2. 갤러리 게시판
일자 : 2026.06.06 
유형 : 신규
현황 : 완료
내용
- 이미지를 등록하고 조회할 수 있는 갤러리형 게시판
- 이미지 등록방법은 파일을 직접 업로드하는 방법과 클립보드의 이미지를 붙여넣기 하는 방법으로 수행
- 이미지 목록은 cinetube 작품목록 방식과 동일하게 구현
- 왼쪽메뉴 하단에 갤러리로 이동할 수 있는 '갤러리' 메뉴 추가
- 갤러리 보기방식은 갤러리 목록 보기, 바둑판형 보기, 슬라이드 보기 기능 제공
- 갤러리 상세보기에서 이미지 수정, 삭제 기능 제공
- 갤러리 이미지도 관신작품 선택, 해제 기능 제공
