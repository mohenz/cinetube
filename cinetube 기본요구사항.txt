유튜브 스타일의 영화정보 관리 사이트 제작을 위한 요구사항이야. 
이 요구사항을 확인하고 사이트를 설계해줘.

기본 PC 사용자를 대상으로하는 웹사이트로 설계하고 모바일에서도 사용가능하도록
반응형으로 설계해줘.

1. 주요관리항목
영화제목
영화코드
카테고리
주연배우
키워드(태그)
평가등급
영상링크
주요내용
포스터
캡쳐
스냅샷
출시년월
제작사

2. 관리기능
1) 카테고리정보 관리
기본정보 : 카테고리코드, 카테고리명, 카테고리대표이미지,전시여부관리

2) 주연배우정보 관리
기본정보 : 배우명, 나이, 신장, 신체사이즈, 데뷔년도, 주연배우대표이미지, 주연배우일반이미지 4개

3) 평가등급정보 관리
기본 등급 : A+, A, B+, B, C

3. main 화면 구성
Home, 영화정보는 한줄에 4개씩 출력
최신등록 8개, 
맞춤추천 8개, 카테고리별 평가등급 상위 8개 영화 출력

top menu : 주연배우, 카테고리, 평가등급
-> 각 메뉴 클릭시 포스터, 영화제목, 영화코드, 평가등급 정보 노출
   영화제목을 사이즈에 맞게 텍스트 자르기하고 나머지는 ...로 표기
-> 각 페이지별 4 X 5로 영화정보 노출하고 페이징
-> 페이징시 전체, 20개, 40개, 80개, 100개 선택 가능, 기본은 20개

주연배우로 조회시 주연배우정보와 출연한 작품리스트 출력
카테고리로 조회시 해당 카테고리에 포함된 작품리스트 출력
평가등급으로 조회시 해당 평가등급에 포함된 작품리스트 출력
