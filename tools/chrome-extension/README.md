# CineTube 123AV & MissAV Exporter 크롬 확장 프로그램

이 도구는 **123AV / MissAV / MissAV.ai** 상세 페이지에서 영화 메타데이터(제목, 품번, 여배우, 출시년월 등)뿐만 아니라 **실제 비디오 스트리밍 주소(.m3u8 HLS 링크)**를 실시간으로 가로채어, 구동 중인 CineTube 로컬 API 서버(`http://localhost:3001`)로 원클릭 직접 등록해 주는 구글 크롬 확장 프로그램입니다.

---

## 주요 기능
1. **Cloudflare 우회**: 브라우저에서 사용자가 정상 주입되어 우회된 세션을 그대로 타고 스크립트가 실행되므로, 스크래핑 차단이 100% 회피됩니다.
2. **실시간 비디오 링크(.m3u8) 갈취**: 영상이 플레이어에서 로드 및 재생을 개시하는 순간 실제 스트리밍 소스 링크를 낚아채어 CineTube `video_url` 필드로 주입합니다.
3. **간편 등록 UI**: 확장 아이콘 클릭 시 파싱된 요약을 보여주고, 수동으로 편집하여 바로 전송할 수 있는 직관적인 다크 모드 팝업 UI를 제공합니다.

---

## 크롬 브라우저에 장착 및 사용 방법

### 1단계: 확장 프로그램 로드하기
1. 구글 크롬 브라우저를 열고 주소창에 `chrome://extensions/`를 입력해 이동합니다.
2. 우측 상단의 **개발자 모드 (Developer mode)** 스위치를 켭니다.
3. 좌측 상단에 생기는 **"압축해제된 확장 프로그램을 로드합니다 (Load unpacked)"** 버튼을 클릭합니다.
4. 이 프로젝트 내에 생성된 아래의 폴더를 선택하여 업로드합니다:
   - 경로: `D:\workspace\cinetube\tools\chrome-extension`

### 2단계: 툴바에 고정하기 (추천)
- 크롬 주소창 오른쪽의 퍼즐 조각(🧩) 아이콘을 눌러 목록에서 **"CineTube 123AV & MissAV Exporter"** 옆의 핀(📌) 버튼을 클릭해 상단 툴바에 고정합니다.

### 3단계: 실제 영화 등록 테스트
1. **CineTube 로컬 환경 구동**: PC에서 `start-cinetube.cmd`를 실행하여 API 서버 및 웹서버가 구동 중인 상태여야 합니다 (`localhost:3001` 열림).
2. 등록하고 싶은 **123AV / MissAV** 사이트의 비디오 상세 페이지(예: `https://123av.com/ko/v/pred-890-uncensored-leaked` 등)로 이동합니다.
3. **영상 재생 개시**: 페이지에 접속한 뒤 영상을 플레이하여 스트리밍 재생이 시작되도록 합니다. (이때 백그라운드 스크립트가 실제 `.m3u8` 비디오 주소를 가로챕니다.)
4. 상단 툴바의 **CineTube Exporter** 아이콘을 클릭합니다.
5. 수집된 품번, 제목, 여배우, 스트리밍 주소를 눈으로 확인 및 필요시 편집한 뒤 **[CineTube로 영화 등록]** 버튼을 클릭합니다.
6. 완료 팝업 알림이 뜨면 등록이 완료되며, CineTube 메인 홈이나 영화 목록 화면에서 새로고침하여 등록된 고화질 비디오를 바로 시청하실 수 있습니다!
