# CineTube 123AV & MissAV Exporter 크롬 확장 프로그램

이 도구는 **123AV / MissAV / MissAV.ai / JavHDporn / Javtiful** 상세 페이지에서 영화 메타데이터(제목, 품번, 여배우, 출시년월 등)와 **비디오 스트리밍 주소(.m3u8 HLS 링크)**를 파싱하여, 구동 중인 CineTube API 서버로 원클릭 직접 등록해 주는 구글 크롬 확장 프로그램입니다.

v1.4부터 **멀티 PC(내부망 클라이언트) 지원**이 추가되어, 동일 네트워크에 있는 다른 PC의 브라우저에서도 서버 IP를 지정하여 영화를 원격으로 등록할 수 있습니다.

---

## 주요 기능
0. **등록 여부 확인 (v1.5)**: 영화정보 수집 후 설정된 서버에서 품번(대소문자 무시)과 원본 페이지 URL을 조회합니다. 이미 등록된 영화는 제목을 표시하고 등록을 막습니다. 품번 또는 서버 주소를 수정하면 다시 확인하며, **[등록 여부 확인]** 버튼으로 수동 재조회할 수도 있습니다. 조회 실패 시 서버 연결을 확인한 뒤 재조회해야 등록할 수 있습니다. 등록 직전에도 한 번 더 조회합니다.
1. **Cloudflare 우회**: 브라우저에서 사용자가 정상 주입되어 우회된 세션을 그대로 타고 스크립트가 실행되므로 스크래핑 차단이 회피됩니다.
2. **동적 CineTube 서버 주소 설정 (v1.4 신규)**:
   - 로컬(`localhost:3001`)뿐만 아니라 내부망 호스트 PC 주소(예: `http://192.168.0.50:3001`)를 자유롭게 입력하여 지정할 수 있습니다.
   - 팝업 내 **[연결 테스트]** 버튼을 통해 서버 상태를 즉시 확인할 수 있습니다.
   - 입력한 서버 주소는 `chrome.storage`에 영구 저장되어 유지됩니다.
3. **간편 등록 다크 UI**: 확장 아이콘 클릭 시 파싱된 요약(품번, 제목, 출시일, 여배우)을 확인 및 편집하여 원클릭 등록합니다.

## 크롬 브라우저에 장착 및 사용 방법

### 1단계: 확장 프로그램 로드하기
1. 구글 크롬 브라우저를 열고 주소창에 `chrome://extensions/`를 입력해 이동합니다.
2. 우측 상단의 **개발자 모드 (Developer mode)** 스위치를 켭니다.
3. 좌측 상단에 생기는 **"압축해제된 확장 프로그램을 로드합니다 (Load unpacked)"** 버튼을 클릭합니다.
4. 확장 프로그램 폴더를 선택하여 업로드합니다:
   - 로컬 PC: `e:\workspace\cinetube\tools\chrome-extension`
   - 다른 PC: 해당 폴더를 USB나 네트워크 공유로 복사한 뒤 해당 폴더를 지정합니다.

### 2단계: 툴바에 고정하기 (추천)
- 크롬 주소창 오른쪽의 퍼즐 조각(🧩) 아이콘을 눌러 목록에서 **"CineTube 123AV & MissAV Exporter"** 옆의 핀(📌) 버튼을 클릭해 상단 툴바에 고정합니다.

## 내부망(다른 PC)에서 사용할 때 서버 설정 방법

1. **호스트 PC(CineTube 서버) IP 확인**:
   - 호스트 PC의 터미널/PowerShell에서 `ipconfig` 명령을 실행하여 IPv4 주소(예: `192.168.0.50`)를 확인합니다.
   - CineTube 서버(`start-cinetube.cmd`)가 구동 중인지 확인합니다.
2. **호스트 PC 방화벽 확인**:
   - 다른 PC에서 접속하려면 호스트 PC의 Windows Defender 방화벽에서 포트 `3001`(API) 및 `8080`(웹 화면)에 대한 인바운드 연결이 허용되어 있어야 합니다.
3. **확장 프로그램 팝업에서 서버 주소 설정**:
   - 다른 PC의 브라우저에서 확장 프로그램 아이콘(🎬)을 클릭합니다.
   - 상단 우측의 **⚙️ [서버 설정]** 또는 하단의 **[변경]**을 클릭합니다.
   - 호스트 PC 주소 입력: `http://192.168.0.50:3001` (자신의 서버 IP 및 포트)
   - **[연결 테스트]** 버튼을 클릭하여 `✅ 연결 성공`이 뜨는지 확인합니다.

## 실제 영화 등록 방법

1. 등록하고 싶은 **123AV / MissAV / JavHDporn / Javtiful** 사이트의 비디오 상세 페이지(예: `https://123av.com/ko/v/...`)로 이동합니다. JavHDporn 주소는 `https://www.javhdporn.net/`, Javtiful 주소는 `https://javtiful.com/kr/main`입니다.
2. **영상 가볍게 재생**: 상세 페이지에서 비디오를 플레이하여 스트리밍 재생이 시작되도록 합니다.
3. 상단 툴바의 **CineTube Exporter** 아이콘(🎬)을 클릭합니다.
4. 자동 조회 결과가 **미등록 영화**인지 확인합니다. 수집된 정보를 필요시 수정한 뒤 **[CineTube로 영화 등록]** 버튼을 클릭합니다.
5. 성공 알림이 뜨면 CineTube 웹 화면(`http://192.168.0.50:8080` 또는 `http://localhost:8080`)에서 새로고침하여 등록된 영화를 바로 감상하실 수 있습니다!

업데이트 후 `chrome://extensions/`에서 이 확장 프로그램의 새로고침 버튼을 누르고 팝업을 다시 여세요.
원본 URL은 정확히 같은 주소만 일치합니다. 다른 사이트의 동일 작품은 품번으로 확인합니다.
이 기능은 등록 전 조회이므로 여러 PC에서 동시에 등록하는 경우까지 원자적으로 차단하지는 않습니다.
